# 高校バスケ選手向け 栄養講習アジェンダ(v5)

**テーマ(仮):「食事は、いちばん再現性の高いトレーニングだ 〜ウィンターカップへ、コートの外で差をつける〜」**

- 対象:バスケットボール部員 20名(寮生8名/通い12名)+ **保護者見学あり**
- 想定時間:本編 約85分+質疑5分(60分への圧縮案は末尾)
- チームの実情:週3回 朝7:00ウェイトトレーニング/練習は毎日16:00〜19:00/寮の夕食は19:30頃
- チーム目標:**県代表になり、ウィンターカップに出場する**
- 目標摂取カロリー:**3,000kcal/日を「チームの最低ライン」に設定**(計算ワークで各自の目標も算出)

> **v5の更新**:山梨学院短期大学公開講座(2021)「スポーツ栄養学を取り入れた中高生の食教育」(鈴木睦代先生・管理栄養士/公認スポーツ栄養士)の内容を、2026年時点の最新知見・最新基準(食事摂取基準2025年版、IOC REDs 2023等)にアップデートして統合。末尾の「2021→2026 アップデート対照表」参照。

## 全体の設計思想

5つの流れを一本のストーリーにする:

1. **実体験(希望の証明)**:講師自身が県ベスト16レベルから日本トップレベルと互角になれたのは、食事で「練習をこなしきれる身体」を作れたから
2. **気づき(現状の自覚)**:自分たちはエネルギーが切れた状態で練習している
3. **科学(危機感)**:ガス欠のまま練習すると、上手くならないどころか怪我が増え、筋肉が減る(論文で裏付け)
4. **体系知識(設計図)**:PFCバランスと自分の必要カロリー。「何を・どれだけ」の全体像を1枚で持ち帰らせる
5. **行動(再現性)**:このチームのスケジュールに合わせた「いつ・何を」に落とし込み、明日の1食目から変える

保護者が見学するため、**専門用語は日常の言葉に置き換え、家庭でできるサポートを明確に**示す。
比喩は「車」で統一する:**糖質=ガソリン/タンパク質=車体・エンジン部品/脂質=エンジンオイル/エネルギー不足=ガス欠**。

## アジェンダ(本編 約85分)

### 1. オープニング:「リングに指先」が「肘まで」になった話(10分)

- **問い①(ペア30秒ずつ):「リングに指先しか届かなかった選手が、肘まで跳べるようになった。その選手は何をしたと思う?」**
  - → 予想をペアで話してから、数名に発表してもらう
- 種明かし=講師自身の実体験:
  - 県ベスト16レベルの選手だった自分が、東海大バスケ部でプロ・日本代表クラスの選手たちとプレーするまでになった
  - **週14回のバスケ+週7回の筋トレ**という練習量をこなせた
  - こなせた理由は、才能ではなく「食事と身体づくり」で練習に耐えられる身体を作ったから
  - 成果:ジャンプ力アップ(リングに指先→肘まで)/当たり負けしない身体/**クイックネスを落とさずに筋肉量だけを増やした**/日本を代表するガードと互角にプレー
- 土台の図(公開講座p4のピラミッドを転用):**結果 ← 心 ← トレーニング・勉強 ← 土台=栄養・カラダ・休養(睡眠)**。「上手くなりたければ、土台から積む」
- キーメッセージ:**「才能で上がったんじゃない。ハードな練習を"こなしきれる身体"を食事で作ったから上がれた」**

### 2. 現状チェック:「昨日、何を・いつ食べた?」(8分)

- **問い②(各自1分でメモ→ペア共有):「昨日食べたもの・飲んだものを、時刻つきで全部書き出してみよう」**
  - ※このメモは後のセクション5(タンパク質チェック)とセクション6(タイムライン作り)でもう一度使う。捨てさせない
- **問い③(挙手でテンポよく。人数をホワイトボードに記録):**
  - 朝7時ウェイトの日、何か食べてから来ている人?
  - 練習前(16時まで)に補食をとっている人?
  - 練習中、水以外(スポーツドリンク)を飲んでいる人?
  - 練習後、夕食までの間に何か口にしている人?
- **エネルギー不足のサイン・セルフチェック(挙手)**:「だるい/疲れが取れない/集中力が続かない/肌荒れ/冷え。2つ以上当てはまる人?」(公開講座p8より)
  - → 「それ、気合いの問題じゃなくて燃料の問題かもしれない」で次のセクションへ
- ねらい:「エネルギーが切れたまま練習している」実態を、**チーム自身の数字**として黒板に可視化する。この数字が後半の伏線になる

### 3. 科学の話:「ガス欠のまま練習していないか?」(13分)

- 講師の現場感覚から入る:**「プロレベルの選手を間近で見てきて、一番差を感じたのがここ。そして高校生を見ていると、エネルギーが切れた状態で練習しているケースがとても多い」**
- **高校生アスリートの必要量は「三階建て」**(公開講座p6の図を転用):
  - 1階=日常生活の分/2階=**成長の分**(今しかない)/3階=トレーニングの分
  - 「大人のアスリートより君たちの方が"割増し"が必要。成長分を削ると身長・骨・筋肉の伸びしろを削ることになる」
- 「エネルギー可用性」を家計簿に例えて図解(保護者にも分かりやすく):
  - 収入(食事)− 支出(練習)= 身体を作る・回復に使える残高
  - 残高がマイナスのまま練習する=**借金しながらトレーニングしている状態**
- 研究紹介(スライド1枚につき数字1つだけ見せる):
  1. **IOC(国際オリンピック委員会)の公式見解**:エネルギー不足(REDs:スポーツにおける相対的エネルギー不足)は、骨・筋肉の合成・免疫・集中力・心血管機能まで幅広く悪化させ、パフォーマンスを下げる(Mountjoy et al., 2014→**2023年更新版**)。**男子にも普通に起こる**(女子だけの問題ではない)
  2. **疲労骨折が約4.5倍**:エネルギー不足状態のエリート陸上選手は、骨のストレス性障害(疲労骨折など)の発生が約4.5倍だった(Heikura et al., 2018)。エネルギー不足→骨密度・骨強度の低下、鉄欠乏性貧血にもつながる(公開講座p10)
  3. **筋肉の合成が27%低下**:エネルギー不足の状態では、安静時の筋タンパク質合成が27%低下=「練習しているのに筋肉が作られにくい・減っていく」。ただし**運動後にタンパク質を摂れば合成は回復する**(Areta et al., 2014)
- **問い④(挙手→数名指名):「練習の後半、足が動かない・集中が切れる・シュートが落ちる。心当たりある人? それは何が原因だと思っていた?」**
- キーメッセージ:**「頑張っているのに強くなれないのは、努力不足ではなく燃料不足かもしれない。ガス欠で練習すると、上手くならないどころか、怪我が増えて筋肉が減る」**

### 4. 希望の話:食事は「誰がやっても効く」(5分)

- **問い⑤(ペア1分→数ペアが全体シェア):「身長・才能・食事。この中で、今日から自分の意思で変えられるのはどれ?」**
- 再現性の説明:
  - シュートセンスは人によるが、**生理学は全員に平等**。正しく食べれば誰の身体でも必ず反応する
  - Areta の研究の続きがまさにそれ:エネルギー不足でも「運動+タンパク質」で筋合成は回復した=**やれば必ず効く**
- キーメッセージ:**「食事は、努力が裏切らない数少ない分野」**

### 5. 体系知識:PFCと「自分の3,000kcal」(18分)

「じゃあ具体的に、何を・どれだけ食べればいいのか」。設計図を持ち帰らせるセクション。車の比喩で統一して説明する。

- **問い⑥(3択クイズ・挙手):「バスケの練習や試合で、メインで使われる燃料はどれ? A:タンパク質 B:糖質 C:脂質」**
  - → 正解はB(糖質)。「プロテインばかり気にして、ガソリンを入れ忘れている選手が多い」という導入に使う

#### C:糖質(Carbohydrate)=ガソリン

| 項目 | 内容 |
|------|------|
| 役割 | 動くためのエネルギー。**脳の燃料**でもある(判断力・集中力・シュートの精度) |
| 不足すると | ガス欠(セクション3の話)。さらに**筋肉を分解して燃料にしてしまう**。体内の貯蔵タンク(筋肉・肝臓のグリコーゲン)は小さいので、毎食+補食でこまめに補充が必要 |
| 食材例 | ごはん、パン、麺、もち、いも、バナナ、果物/(補食向き)おにぎり、カステラ、あんぱん、エネルギーゼリー、100%ジュース |
| 目安 | ハードに練習する選手は**体重1kgあたり6〜10g/日**(ACSM)。「ごはん茶碗1杯で糖質約55g」と換算して見せる |

#### P:タンパク質(Protein)=車体・エンジンの部品

| 項目 | 内容 |
|------|------|
| 役割 | 筋肉・骨・血液・腱・皮膚の**材料** |
| 不足すると | 筋肉が増えない・怪我が治りにくい(「27%低下」の話とつながる) |
| 食材例 | 肉、魚、卵、納豆・豆腐などの大豆製品、牛乳・ヨーグルト・チーズ |
| 目安 | バスケのような高強度・断続型競技は体重×1.4〜1.7g/日、**成長期は1割増しで体重×1.5〜1.9g/日**。2g/kgを超えて摂る必要はない(それ以上は上乗せ効果がほぼない) |

- 食材換算表(スライド1枚):**肉・魚100g→約20g/卵1個→約6g/納豆1パック→約8g/牛乳コップ1杯→約7g**
- **ミニワーク(2分・ペア):「自分の体重×1.5〜2=1日の目標(g)。問い②で書いた昨日の食事、何gとれていたか概算してみよう」**
  - → ほぼ全員が目標に届いていないことに自分で気づく(講師が言うより効く)

#### F:脂質(Fat)=エンジンオイル

| 項目 | 内容 |
|------|------|
| 役割 | ホルモンの材料、細胞膜、長時間運動のエネルギー、ビタミンの吸収 |
| ポイント | **少なすぎも多すぎもNG**。成長期はホルモンの材料として必須。「脂質は少なければ少ないほど良い」は誤り(公開講座p9) |
| 良い摂り方 | 青魚(サバ・イワシ)、卵、ナッツ、オリーブオイル |
| 注意 | 揚げ物・スナック菓子・菓子パンに偏るとすぐオーバーする。**消化が遅いので練習前は控えめに**(→セクション6の「補食は脂質少なめ」の理由づけ) |

#### ★計算ワーク:「自分の必要カロリー」を出してみよう(公開講座p16-17の式を転用)

- **問い⑦(各自電卓→ペアで見せ合い):**

  > **必要カロリー = 27.0(基礎代謝基準値:15〜17歳男子)× 自分の体重(kg)× 2.00(バスケ・3時間練習のPAL)+ 10(成長分)**

  - 例:体重55kg → 約2,980kcal/60kg → 約3,250kcal/70kg → 約3,790kcal
  - PAL(身体活動レベル)表:バスケは「球技系・激しい」で練習1時間1.65/2時間1.80/**3時間2.00**
  - **朝ウェイトの日はこの計算に含まれていないので、さらに上乗せが必要**
- 結論:**「3,000kcalはこのチームの"最低ライン"。自分の計算値が本当の目標」**(個人差が大きいので人と比べない。体重の推移を見て調整する)
- 参考:デスクワーク中心の成人男性は約2,200kcal。**「お父さんの1.4倍以上食べるのが、君たちの仕事」**(保護者に強く刺さるスライド)
- **体感換算:「コンビニおにぎり1個は約180kcal。3,000kcalはおにぎり約17個分」**。普通の3食では2,000〜2,400kcalしか取れない → **足りない600〜1,000kcalは「朝食の増量+補食2回」で埋める**(次のセクションへの橋渡し)

| 魚 | 70g |
| 卵 | 1個 |

- キーメッセージ:**「量(カロリー)が土台、バランス(PFC)が設計図。そして君たちに一番足りていないのは、まず"量"」**

#### ★実例スライド:私の大学時代の食事パターン(時系列)

「自分の計算値って実際どんな1日?」に、講師自身の東海大時代の実例で答えるスライド。

- 見せ方:縦のタイムライン(起床〜就寝)に、**バスケ・筋トレの時間と食事・補食のタイミングを重ねて**1枚で見せる
- 盛り込むポイント(実際の内容はご自身の記憶で具体化):
  - 週14回のバスケ+週7回の筋トレの「どこで・何を」食べてエネルギーを切らさなかったか
  - 練習前後の糖質、毎食のタンパク質など、次のスライド(おすすめ食事例)と対応する構造にしておく
  - 完璧な食事ではなく「工夫していたリアル」も1つ入れる(学食・コンビニの使い方など)と高校生に刺さる
- キーメッセージ:**「この食事があったから、あの練習量をこなせた。特別なことではなく、毎日の積み重ね」**

### 6. 実践編:このチームの24時間を設計する(19分)

このチームの実際のスケジュールをタイムラインで貼り出し、セクション5の設計図を「いつ・何を」に当てはめていく。

#### ★おすすめの1日の食事例(時系列・モデルケース)

「私の大学時代」スライドと同じタイムライン形式で、**このチーム版のおすすめ**を1枚で見せる(合計が約3,000kcalになる設計)。

| 時刻 | 食事 | 内容例 | 目安kcal |
|------|------|--------|----------|
| 6:15 | ウェイト前(週3) | バナナ+エネルギーゼリー | 約150 |
| 8:00 | 朝食 | ごはん大盛+卵+納豆+味噌汁+牛乳 | 約700 |
| 12:30 | 昼食 | 弁当(ごはん・肉か魚・野菜)+パック牛乳 | 約750 |
| 15:30 | 練習前補食 | おにぎり1〜2個+バナナ | 約300 |
| 16:00〜19:00 | 練習中 | スポーツドリンク約1L | 約150 |
| 19:05 | 練習直後 | 寮生:牛乳かゼリー/通い生:おにぎり+プロテインか牛乳 | 約200 |
| 19:30〜20:30 | 夕食 | 主食+主菜+副菜+汁物 | 約800 |
| 21:30 | 就寝前 | 牛乳かヨーグルト | 約100 |

- **合計:約3,000kcal(朝ウェイト日は約3,150kcal)** — 最低ラインがこの1日で達成できることを見せる。計算値が大きい選手は各食を増量
- ポイント:**3食は今より「少し増やす」だけ。差がつくのは色付きの行(補食・練習中・直後)**=食事回数を3回→6回に増やす発想

#### 補食セルフチェック(公開講座p22を転用・挙手ワーク)

「補食が必要な人」チェック — 1つでも当てはまれば補食対象:
- 最後の食事から2〜3時間以上空いて練習する(**昼食12:30→練習16:00は3.5時間。全員該当!**)
- きつい負荷の練習・ウェイトをする
- 体重・筋量を増やしたい
- 練習後、夕食まで30分〜1時間以上空く(通い生は特に)

#### 練習前の補食:「時間で変える」(公開講座p23)

- **練習の1.5〜2時間前に食べられるなら**:おにぎり、巻き寿司、麺類、団子(=食事寄りの糖質)
- **練習の1時間前〜直前(15:30の下校後など)**:バナナ、カステラ、あんぱん、100%ジュース、エネルギーゼリー(=消化の早い糖質)
- **朝ウェイト前(6:15)も同じ考え方**:1時間を切っているのでバナナ・ゼリー・ジュース系
- 共通ルール:**糖質中心・脂質少なめ**(脂質は消化が遅い)

#### 練習中:水分と糖質を同時に(公開講座p53-55+Dougherty研究)

- **脱水は体重の2%でアウト**:2%失うと強い渇き・めまい・集中力低下=パフォーマンス低下(12〜15歳バスケ選手の研究でも2%脱水でスキル低下、**6%糖質電解質ドリンクは水よりシュート成功率とスプリントが向上**:Dougherty et al., 2006)
- 実践プロトコル:
  - 練習20〜40分前:250〜500ml(水・麦茶・スポーツドリンク)
  - **練習中:1時間あたり500〜1,000mlを、15分おきくらいに分けて飲む**(3時間練習なら合計1.5〜2L目安)
  - 中身は「糖質約4〜8%+塩分入り」=**市販スポーツドリンクの濃度がちょうど良い**(ポカリ・アクエリは約5〜6%)。ジュース・サイダーは約11%で濃すぎて吸収が遅い。**エナジードリンクはカフェインが多くスポーツドリンクではない**(公開講座p56-57)
- **宿題ワーク:「明日の練習の前後に体重を測ってみよう」**減った分≒汗の量。自分の必要量を知る(公開講座p55)

#### 練習直後〜夜:回復の3段階(公開講座p25を2026年版に更新)

1. **練習直後〜早めに**:糖質+タンパク質(バナナ+牛乳、おにぎり+プロテインなど)
   - **寮生(8名)**:19:30に夕食があるので、直後は牛乳やゼリー程度で軽く→**夕食が回復の本番**。高価なサプリは必須ではない
   - **通い生(12名)**:帰宅・夕食まで時間が空くので、**ここでの補食が最重要ポイント**
   - ※「30分以内でないと無意味」ではない。最優先は1日の総量。ただこのチームは**翌朝7時ウェイト**があるので、早めの補給が理にかなう
2. **夕食**:主食+主菜+副菜+汁物でしっかり
3. **睡眠**:寝ている間に成長ホルモンが出て身体を作る=**超回復**(トレーニング→食事→睡眠→強くなる)。時刻の魔法はないが、**8時間以上+毎日同じリズム**。朝6時起き(ウェイト日)から逆算すると22時台就寝

#### 「お腹がいっぱいで食べられない」問題の解決(保護者にも重要)

- 原因は本人のやる気ではなく「タイミングと形」。練習直後に食欲が落ちるのは生理的に普通のこと(運動中は消化・吸収が抑制される:公開講座p7)
- 解決①:おにぎりは「練習後」ではなく**「練習前15:30」に回す**(同じおにぎりが2倍生きる)
- 解決②:練習直後は固形ではなく**液体・半固形**(牛乳、飲むヨーグルト、ゼリー飲料、バナナ)
- 解決③:一度に食べきらず**分割する**(半分を練習前、半分を練習後)
- 解決④(少食の選手向け・長期):**「めし1口」作戦**(公開講座p11)— まず朝食にごはん1口だけ追加→1週間続いたら昼にも1口→と段階的に増やす。**胃も練習で大きくなる**

#### コンビニ実践クイズ:「菓子パンは菓子であってパンではない!」(公開講座p32)

- クイズ(挙手):「ごはん300gとメロンパン1個、太りやすいのはどっち?」
  - ごはん300g=468kcal・脂質0.9g/メロンパン=279kcal・**脂質8.4g**/クロワッサン=219kcal・**脂質13.4g**
  - → 菓子パンは「ガソリン」のふりをした「オイルの塊」。補食はおにぎり・あんぱん・カステラ系(脂質少)を選ぶ
- 通い生向けワーク:「コンビニ500円。練習前用と練習後用の2袋に分けて買うなら?」→ 数名発表→講評

### 7. 保護者の皆さんへ(6分)

- まず感謝から:おにぎりを持たせるサポートは**すでに正解**。変えるのは「何を」ではなく「いつ」
- 家庭でお願いしたいことは3つだけ:
  1. **朝ごはんの「定食化」**:ごはん+タンパク質(卵・納豆・魚)+汁物。特に朝ウェイトの日。**朝食を抜くと筋肉の材料切れで、せっかくの朝ウェイトが逆効果になりかねない**
  2. **補食セットの準備**:おにぎり+バナナ+パック牛乳(飲むヨーグルト)。「練習前に食べてね」の一言を添える
  3. **夕食に主菜+副菜**:肉・魚・卵・大豆の主菜と、野菜の副菜を一品ずつ(3,000kcal食品構成表を買い物リストとして配布)
- コンディションを支える栄養素(1枚で):**カルシウム**は乳製品600ml/日+小魚・青菜(骨=疲労骨折予防)、**鉄**はレバー・赤身肉・あさり・納豆・青菜を意識(貧血=スタミナ切れ予防。疲れやすさが続く場合は自己判断のサプリではなく血液検査を)
- **プロテインサプリQ&A**:「買うべきですか?」→ **まず食事とタイミングの見直しが先**(公開講座p48)。寮生は夕食が近いので基本不要。使う場合は食事の代わりにせず、第三者認証(アンチ・ドーピング)のある製品を
- 量の目安も一言:**「育ち盛り+毎日3時間練習で、必要量は1日3,000kcal以上=お父さんの約1.4倍。ごはんのおかわりは甘やかしではなくトレーニングです」**
- キーメッセージ:**「特別な食材も高価なサプリも不要。いつものご飯の"量とタイミング"を整えるだけです」**

### 8. クロージング:「ウィンターカップへの1,100回」(8分)

- **問い⑧:「今日の話の中で、明日からまず変える『1つ』は何?」**
  - → 各自で書く(1分)→ ペアで宣言し合う → 数名が全体に宣言(保護者からも一言もらえるとなお良い)
- 締めのストーリー:
  - 県代表になるチームと自分たちの練習時間に、実は大差はない。**差がつくのは残りの21時間**
  - 食事は1日3回+補食=年間約1,100回のトレーニング機会
  - **ウィンターカップ予選までに残された食事回数をその場で計算して見せる**(例:約120日 × 4回 ≒ 500回。「この500回を勝ちにつなげるか、捨てるか」)
- 最後の一言:**「明日の朝ごはんが、ウィンターカップへの1回目」**
- (可能なら)1週間後にチームで振り返る仕組みを予告(補食の写真共有、練習前後の体重測定の結果共有など)

## 参加型にするための「問い」一覧

| # | 問い | 形式 | ねらい |
|---|------|------|--------|
| ① | 指先しか届かなかった選手が肘まで跳べるようになった。何をしたと思う? | ペア→全体 | 講師の実体験への引き込み。答えが「食事」だと知る驚き |
| ② | 昨日食べたもの・飲んだものを時刻つきで書き出そう | 記入→ペア | 現状の無関心を自覚させる。⑥・タイムライン作りで再利用 |
| ③ | 朝ウェイト前に食べてる?練習前補食は?練習中スポドリは?+エネルギー不足サインチェック | 挙手(人数記録) | チームの実態を数字で可視化。後半の伏線 |
| ④ | 練習後半に足が動かない経験は?原因は何だと思っていた? | 挙手→指名 | 「ガス欠」を自分の実体験と結びつける |
| ⑤ | 身長・才能・食事、今日から変えられるのは? | ペア→全体 | 「再現性」を自分の言葉で気づかせる |
| ⑥ | 【クイズ】練習でメインで使われる燃料は?/体重×1.5〜2gのタンパク質、昨日とれてた? | 3択挙手+ペア概算 | PFCの知識をクイズと自己採点で「自分ごと」にする |
| ⑦ | 【計算ワーク】27.0×体重×2.00+10=自分の必要カロリー | 電卓→ペア | 「3,000kcalは最低ライン」を自分の数字で実感させる |
| ⑧ | 明日からまず変える「1つ」は? | 記入→ペア宣言→全体 | 行動宣言。講習を行動につなげる要 |

このほかの体を動かす仕掛け:補食セルフチェック(挙手)/菓子パンクイズ(挙手)/コンビニ500円ワーク(ペア)/宿題=練習前後の体重測定。

### 問いづくり・運営のポイント

1. **「正解のある質問」より「自分の経験を話す質問」**にする(沈黙しない)。知識を扱うときは⑥⑦のように**クイズ・計算形式**にして全員参加にする
2. **挙手 → ペア → 全体の順**で心理的ハードルを上げていく
3. **挙手の人数はホワイトボードに記録する**:後半の実践編で「この数字を変えよう」と回収できる
4. **プレーの実体験と結びつける問い(④)を核にする**:「栄養の話」ではなく「自分のプレーの話」に変わる瞬間を作る
5. **一度書かせたもの(②)は後で再利用する**:「昨日の記録」をタンパク質の自己採点(⑥)と明日のタイムライン作りで使うと、学びが自分の生活に接続される
6. **最後は必ず「宣言」で終える**(コミットメント効果)
7. **保護者がいる場では、選手を責める形の問いにしない**:「食べていない人?」ではなく「食べてから来ている人?」とポジティブ側で挙手させる

## 保護者向けの伝え方の工夫

- 専門用語は日常語に置き換える(車の比喩で統一):
  - 糖質 → 「ガソリン」/タンパク質 → 「車体・エンジンの部品」/脂質 → 「エンジンオイル」
  - エネルギー可用性 → 「収入と支出、残高の家計簿」
  - 筋タンパク質合成 → 「筋肉の工場の稼働率」
  - REDs → 「スポーツ版のエネルギー赤字」
- 研究データは**1枚のスライドに数字1つ**(4.5倍/27%/6%/2%)に絞る
- カロリーは kcal の数字だけでなく**「おにぎり◯個分」「お父さんの1.4倍」「ごはん900g=茶碗6杯」**に換算して見せる
- 家庭へのお願いは**3つまで**。3,000kcal食品構成表を**買い物リストの形で配布**すると行動につながりやすい

講義で古い情報をそのまま話さないためのメモ。スライド化はしない。

| 公開講座(2021)の記載 | 2026年時点の扱い |
|---------------------|-----------------|
| 食事摂取基準2015/2020年版ベースの数値 | **2025年版**に出典を更新(15〜17歳男子の推定エネルギー必要量3,150kcal・PFC目標量は同水準。基礎代謝基準値27.0等の枠組みは継続) |

| 「回復のゴールデンタイム=運動後30分以内」 | 「30分」の厳格な時間枠は緩和されている(ISSN 2017等)。**最優先は1日の総量**、ただし翌朝ウェイト等で次の運動が近い場合は早めの糖質+タンパク質が有効、と説明 |

| プロテイン過剰摂取で「肝臓・腎臓に負担」「骨が弱くなる」 | 健康な人での害の根拠は弱い。**「まず食事の見直しが先決」という主メッセージだけ残し**、臓器障害の断定はしない。使うなら認証品 |
| 「成長ホルモンは22時〜2時に分泌」 | 時刻ではなく**入眠後の深い睡眠**に連動。「8時間以上+規則的な就寝」に言い換え |

## 60分に圧縮する場合の調整案

- セクション4(希望・再現性)をセクション3の末尾に統合(5分→3分)
- セクション5:PFC解説を「クイズ⑥+設計図1枚」に圧縮し、食材換算表・食品構成表は配布資料へ。計算ワーク⑦と大学時代スライドは残す(18分→11分)
- セクション6:補食セルフチェックと菓子パンクイズを配布資料へ。おすすめ食事例・水分プロトコル・おにぎり問題は残す(19分→13分)
- 問い①と②のペアシェアをどちらか片方に絞る(計3分短縮)
- ※「大学時代の食事パターン」「おすすめ食事例(時系列)」「計算ワーク」の3つは圧縮版でも削らない(この講習の核のため)
