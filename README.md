# シンプルアラーム (Simple Alarm)

ブラウザだけで動く、とてもシンプルなアラームアプリです。ビルド不要・依存ライブラリなしの単一 HTML ファイルで構成されています。

## 使い方

`index.html` をブラウザで開くだけです。

1. 時刻を入力する
2. 「アラームをセット」を押す
3. 設定時刻になると音が鳴り、画面が点滅します
4. 「停止 / 解除」で止められます

## 機能

- リアルタイムの時計表示
- 指定時刻でのアラーム（Web Audio API によるビープ音）
- 鳴動中の画面フラッシュ
- アラームの解除

## 技術

- 単一の `index.html`（HTML / CSS / JavaScript）
- 外部依存なし
